# DriveGauge 1.2.0

- Добавлен отдельный адаптивный тест сетевых дисков SMB, NFS и WebDAV.
- Сетевой ввод-вывод выполняется в изолированном worker-процессе и не блокирует интерфейс.
- Объём теста автоматически подстраивается под скорость соединения и выбранный максимум.
- Показываются точные записанные и прочитанные байты, прошедшее время, ETA и отсутствие передачи.
- Watchdog автоматически останавливает зависший сервер; ручная остановка ограничена по времени.
- Временный файл создаётся через `O_EXCL` с UUID и удаляется только по точному пути текущего запуска.
- История SQLite хранит тип сети, фактический объём, длительности и версию алгоритма.
- Добавлены диагностика, безопасная миграция базы и расширенные тесты сетевого движка.
- Сборка предназначена только для Apple Silicon (`arm64`).
